# Frontend — Sales Canvassing BMT

React + Vite SPA. UI mengikuti prototype (orange/navy/cards/bottom nav).

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

App: `http://localhost:5173` (proxy `/api` → `http://localhost:8000`)

## Build

```bash
npm run build
```
